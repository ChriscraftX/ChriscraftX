# ¡Hola! Soy Cristian

> Aprender también es una forma de existir.

Soy estudiante de **Informática** y me interesa entender cómo funcionan las cosas por dentro y cómo se conectan entre sí.

Mi interés por el desarrollo de software nace de una convicción: no quiero limitarme a utilizar herramientas, también quiero comprender qué sucede detrás de ellas, qué problemas resuelven y cómo encajan dentro de sistemas más grandes.

El desarrollo web es mi punto de partida, pero no el límite de lo que quiero aprender.

Mi intención es construir, experimentar, equivocarme y entender. Proyecto a proyecto.

## Áreas que me interesan

- **Desarrollo de software:** desde el frontend y el backend hasta las bases de datos, APIs e infraestructura.
- **Arquitectura de software:** comprender cómo se diseñan, estructuran y relacionan los sistemas.
- **Desarrollo móvil y ciberseguridad:** áreas que también quiero explorar.

## Una convicción

Prefiero comprender el porqué de las cosas, cuestionar las decisiones y aprender construyendo.

Creo más en el conocimiento que se construye que en el que simplemente se acumula.
